What this has that others don't

Data nobody else publishes

Most Monad tooling reads the chain. This reads a validator's own consensus log, which is the only place block authorship appears.

◈

VDP compliance

Weekly uptime against the 98% line, with strike counts inside the rolling 3-month window. The Foundation publishes no uptime API, so operators cannot otherwise verify their own standing.

◉

Uptime that outlives the window

Raw rounds roll over after 48 hours. Permanent per-epoch snapshots keep 30-day, 90-day and all-time figures long after the events are gone.

◐

Changes before they land

Commission and stake changes are committed on-chain an epoch before they activate. Both values are exposed, so a commission rise is visible while it is still pending.

◇

An event log the chain doesn't keep

Delegations, withdrawals and commission edits are indexed as they are emitted. The chain keeps no queryable history, so anything not captured live is unrecoverable.

⬡

Set transitions

Who enters the active set next epoch, who leaves, and who is eligible but below the top-200 cut — derived from all three validator sets.

≡

APR you can audit

Two figures, not one: the yield the documented block time implies, and the yield the measured block time gives. Every input is returned so the number can be recomputed.

Quick start

One request, no key

Every endpoint is a GET. Staking routes allow 60 requests per minute per IP and return standard rate-limit headers; validator routes are unmetered.
